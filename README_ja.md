* ⚡ 非常に高速
* 📝 有効性が確認済み

## 📦 使用方法
当サイトの無料プロキシを入手する方法は多数あります。

`.txt`ファイルとしてリスト全体をダウンロードするだけでも構いません。

### 🔑 取得する



#### HTTPプロキシ
```shell

```


#### SOCKS4プロキシ
